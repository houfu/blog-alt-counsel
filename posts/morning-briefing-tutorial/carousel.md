Format: 1080x1350 (4:5). One idea per page, teaching deck.

Production: transpose by hand into Canva, same as the watermark deck. This file
records the copy and what each page needs.

## Design rule for this deck

**Teach, don't argue.** Same rule as the watermark deck, and the same mechanism:
the point lands by sequence, not by assertion. Page 4 shows what the source
warrants. Page 5 shows what the agent came back with. Page 6 names why the
second picture is a problem. The reader gets there first; the deck never says
"and this is why you must be careful."

Target: **under 35 words a page.** If a page needs a paragraph, it's two pages.

**Pages 4 and 5 are the hinge and must be laid out identically** — same mono
block, same column widths, same treatment. Page 4 is a clean, correct result.
Page 5 is the same shape of output with one date sixteen years out of place. The
deck turns on the reader noticing the difference without being told.

**Screenshots: don't screenshot a terminal.** Three pages carry real tool output
(4, 5, 7). Set them as styled mono text blocks in Canva so the type is
consistent with the rest of the deck. The exact content is given below and every
line of it is real output, verified 2026-08-30 — do not paraphrase it.

No code. You write the sentences. The agent does the calling.

## Page 3 — The step everyone skips

**Ask what the source has before you write a line of it.**

You don't type the query. You say:

> *"Show me what's in there — the databases, the tables, the full schema. List the columns; don't summarise them."*

## Page 6 — The tool did exactly what I told it to

**`search` answers "about what". `query_table` answers "since when".**

A briefing is a "since when" question. I had read both descriptions and still
wrote the wrong one.

## Page 7 — So make it show its work

**[VISUAL — the prompt, styled as on page 3]**

> *"Before you write the briefing, show me every tool call you're about to make and what each one returned."*

Then read the dates. Not the summaries.

## Why this sequence

The post's own turn is the 2010 result, and it works on the page for the same
reason it works in the post: **the output looks completely normal.** A deck that
opened with "AI makes mistakes" would be arguing. A deck that shows a tidy list
of five real enforcement items and lets the reader spot the sixteen-year-old one
has already made the argument, and the reader made it.

That is also why page 5 gets no highlighting. The moment you circle the date in
red you have done the reader's work and the page stops teaching.
